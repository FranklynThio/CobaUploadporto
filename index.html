02 — Profile

Student by enrollment,
application developer by practice.

I am an Informatics student at Bina Nusantara University (expected 2027), currently spending a full year inside Qpro Sukses Mandiri as a full-stack Application Developer on hospital software.

Healthcare systems taught me something a campus project never could: code has to survive. A registration or billing module written years ago on .NET Framework 4 is still serving a real clinic tomorrow morning, while the new service beside it runs on .NET 9. Most of my work lives in that seam — reading unfamiliar legacy code, extending it without breaking the flow nurses and admin staff depend on, and building the new parts properly.

Before that, my ground was interface work — UI/UX design, front-end, and mobile. I still carry it: the fastest backend in the world is useless if the person at the front desk cannot find the button.
